# Original Boom 2025 plan assets

The SVG in this folder is an original geometric placeholder authored for this
independent project. It is not copied, traced, or derived from the official
reference JPG in `docs/`.

The user owns delivery of the final original SVG and license-clean icons.
Until that artwork arrives, `assets/map/boom-2025-plan.svg` and
`public/map/boom-2025/plan-base.svg` remain documented placeholders.

Do not copy official artwork, logos, or typography into `public/`.
